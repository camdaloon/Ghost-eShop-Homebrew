# Ghost-Eshop-Alternative-3DS
An Alternative eShop for the Nintendo 3DS family of systems.

# Info:
- For some reason the official Ghost Eshop owners decided to change to the new "Freshop" which doesn't work well and has not great background music, so I decided to post a more outdated version for yalls to enjoy where you can just download the cia or scan the qr code :)

# Download
### Requirements
- Latest version available:

- A Modded Nintendo 3DS(XL)/2DS/NEW3DS(XL)/NEW2DS(XL)

- An SD Card with at least 500 MB to install games
